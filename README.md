# Orbit

Orbit is a desktop workspace for Claude Code. It brings your projects and terminal sessions together in a native Mac interface, while Claude Code remains responsible for conversations, commands and permissions.

## Download

Get the [latest release](https://github.com/imadAttar/orbit/releases/latest) for **Mac Apple Silicon**.

[Claude Code](https://code.claude.com/docs/en/setup) must be installed and authenticated separately.

## Development

Requires Node.js, Rust and the [Tauri prerequisites](https://v2.tauri.app/start/prerequisites/).

```bash
npm ci
npm run tauri -- dev
```
